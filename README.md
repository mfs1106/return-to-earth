# RETURN TO EARTH

可交互的 **SpaceX Falcon 9 一级回收**、**Starship / Super Heavy** 三维演示，以及独立的 **Starbase 全设施静态结构探索器**。
项目使用原生 HTML / CSS / JavaScript 与 Three.js，所有模型、纹理、粒子、天空与环境均由代码程序化生成，不依赖私有模型、付费素材或外部图片。

新增的 `全设施拆解 / EXPLORE STARBASE` 页面不播放飞行时间线，只用于结构教学：把发射塔、两根抓取机械臂、发射平台、Super Heavy、Starship 和两级连接拆成稳定层级的 121 个可探索部件。

> 核心事实边界：官方数据只包括飞行器构型、部件用途，以及参考任务页公布的事件时间。高度、速度、燃料、节流曲线、姿态、镜头与落点均为**简化模拟 / 估算**，不是 SpaceX 遥测或内部飞控数据。

## 0. 怎么打开（重要）

**不要直接双击 `index.html`。** 那是 Vite 的开发源码入口，里面的 CSS / ES Module 需要本地服务器解析；用 `file://` 打开只会看到没有样式的原始 HTML，并可能出现 `CORS` / 模块加载错误。这并不是文件写错。

有三种正确打开方式：

### 方式 A：直接双击单文件版（最简单，不需要服务器）

双击项目根目录的 **`RETURN-TO-EARTH.html`**。

这是把所有 CSS、Three.js 代码和资源都内联后的独立文件，包括新的 **Starbase 全设施拆解** 页面；可以直接用 `file://` 打开，首次打开不需要安装依赖。代码修改后运行：

```bash
npm run build:standalone
```

会重新生成 `RETURN-TO-EARTH.html`。

### 方式 B：双击一键启动脚本（推荐开发时使用）

双击 **`start.cmd`**。

脚本会自动：

1. 检查 Node.js；
2. 首次运行缺少 `node_modules` 时自动执行 `npm install`；
3. 构建生产版本并启动本地预览服务 `http://localhost:5173/`；
4. 等待几秒后自动打开浏览器。

保持命令行窗口开启；关闭窗口或按 `Ctrl+C` 停止服务。如果 5173 端口被占用，先关闭之前的服务器窗口。开发时若需要热更新，请使用下面的命令行方式运行 `npm run dev`。

### 方式 C：命令行

要求 Node.js 18+，npm。

```bash
cd return-to-earth
npm install
npm run dev
```

打开终端显示的地址（默认 <http://localhost:5173>）。

生产构建与本地预览：

```bash
npm run build           # 生成 dist/
npm run build:standalone # 生成单文件版 RETURN-TO-EARTH.html
npm run preview         # 默认 http://localhost:4173
```

`dist/` 中的普通构建版本需要通过 HTTP 静态服务器访问；如果希望直接双击打开，请使用 `RETURN-TO-EARTH.html` 单文件版。

## 3. 已实现内容

### Falcon 9 主场景

- **Crew-12（陆地 / RTLS）** 与 **Starlink 10-38（海上 / ASDS）** 两套独立任务。
- 发射台待命 → 倒计时 → 点火升空 → 最大动压 → MECO → 两级分离 → 二级点火 → 一级翻转 → 返航点火（仅陆地任务）→ 再入点火 → 栅格翼气动引导 → 着陆点火 → 着陆腿展开 → 垂直着陆 → 任务总结。
- 一级、二级是独立的 Three.js `Group` 与独立轨迹；分离后分别采样位置、速度、姿态、燃料和发动机状态。
- 陆地任务有 4 条着陆腿与 LZ-1；海上任务使用无人船，**没有插入官方未公布的返航点火**。
- 尾迹路径、发动机火焰、地面烟雾、凝结云、再入热效应、着陆闪光与激波环。
- 七个镜头：全景 / 地面 / 跟随整箭 / 跟随一级 / 跟随二级 / 着陆平台 / 自由轨道。
- 任意拖动时间轴、暂停、重播、0.5× / 2× / 4×；默认 2× 播放，比初版快一倍，任务事件时间戳与轨迹比例不变。

### 拆解与剖面

- 整箭 / 剖面 / 爆炸拆解三种教学视图。
- 8 个可点选部件：一级箭体/贮箱、9 台 Merlin、级间段、4 片栅格翼、4 条着陆腿、二级箭体、Merlin Vacuum、载荷/整流罩。
- 点击部件显示功能说明，右侧出现高亮包围盒；支持一键复原。
- 界面明确说明：拆解只是教学展示，不代表真实任务会分离这些部件。

### Starship / Super Heavy 独立模式

- 独立的 Starship 场景和模拟时钟，**不与 Falcon 9 回收机构混用**。
- 33 台 Super Heavy 发动机、Super Heavy / Starship 两级、热分离、助推器返航、再入、发射塔机械臂捕获；**没有着陆腿**。
- 塔臂在捕获前合拢，捕获时有闪光、冲击环和状态提示。
- 页面标注参考版本为 **Flight 13 时代构型的概念模型**，不是官方逐秒时间线。

### 全设施拆解 / EXPLORE STARBASE

从顶部栏的 **全设施拆解** 进入。它是覆盖在飞行演示之上的独立静态结构探索器；关闭后原来的 Falcon 9 / Starship / HLS 状态保持不变。

- **两种静态教学姿态**：整箭置于发射平台；Super Heavy 位于机械臂捕获位。捕获姿态会暂时隐藏 Starship，并把助推器提升到塔臂高度，便于观察接触关系。
- **121 个稳定部件节点**：发射塔（主柱、斜撑、平台、导轨、提升机构、塔顶、照明、管线）、左右机械臂及子部件、发射平台（基础、台面、轨道支座、固定区域、导流结构、检修结构）、推进剂储罐区、地面照明、Super Heavy（外壳、环焊缝、整流罩、栅格翼、热分离段、发动机舱、33 台 Raptor、示意贮箱）、Starship（箭体、鼻锥、热防护瓦、前/后襟翼、6 台发动机、示意贮箱）、两级连接与发射接触区域。
- **连续拆解深度**：0–100% 滑杆，以及整装 / 一级拆解 / 二级拆解 / 细部拆解预设。每个节点从基准矩阵重新计算姿态，不累积漂移；任意位置都能正确显示。
- **拆解范围**：全部 / 只拆塔架 / 只拆平台 / 只拆火箭；“全部复原”和“复原当前总成”都不会丢失当前选中部件。
- **选择与层级**：左侧树、搜索、三维点击、悬停提示、详情面板；每个总成可展开、聚焦、隐藏、半透明、局部拉出、旋转、归位。内部贮箱从树中选中时会自动切到 X-Ray。
- **壳体透明 / 局部剖面**：X-Ray 下外壳不参与拾取，可点选内部部件；剖面范围可选全部、Super Heavy、Starship、发射塔、发射平台。剖面平面会随视角转动，保持面向观察者。
- **单件交互**：详情面板提供单件偏移滑杆、45° 旋转、拖拽模式；拖拽模式下鼠标移动所选部件而不是相机。相邻部件自动淡化开关默认关闭，打开后只淡化非当前层级部件。
- **五个镜头导览**：整套设施 / 塔臂接触 / 发射支座 / 助推器发动机舱 / 热防护与襟翼。单个部件也可以平滑聚焦。
- **移动端**：树变为左抽屉，详情变为底部抽屉，底部拆解控制保持可操作；触控单指旋转、双指缩放/平移。
- **资料边界**：每个部件带有公开资料 / 教学示意 / 比例估算标签；详情面板显示来源线索和官方链接。页面明确标注参考版本与生成日期，不把教学剖面当作工程图。
- **键盘**：`0` 复位视角，`F` 适应视图，`A` 整装，`E` 拆解，`X` X-Ray，`S` 剖面，`1–5` 导览，`Esc` 关闭；结构树支持方向键、回车与空格。

### 建模方式与 Blender 说明

本网页的模型是**运行时程序化 Three.js 几何**，不是预先导入的 GLB：

- 每个部件拥有稳定 ID、独立 Group、基准矩阵、材质集合与教学元数据；
- 这样 X-Ray、局部透明、独立拆出、单件旋转、稳定拾取和单文件离线构建都无需外部资源；
- 所有比例、内部结构、机构传动、管线和发动机细节为教学示意或比例估算。

当前环境虽然存在 `C:\Program Files\Blender Foundation\Blender 4.4` 目录，但其中没有可执行的 `blender.exe` / `bpy`，因此无法在本机实际执行 Blender 建模、生成或导入 `.blend` / `.glb`。本项目没有把 Blender 文件作为运行依赖；如后续在可用 Blender 的环境中制作高模，可以在保持同名层级 ID 的前提下替换 `StarbaseExplorerModel.js` 的几何层，交互层无需重写。

### 交互与可访问性

- 开始、暂停、重播、任意时间拖动、三档速度、任务切换、画质切换、声音开关。
- 自动演示 / 手动挑战（返航强度、着陆点火高度、横向偏移、再入迎角）。
- 手动挑战输出成功、偏离、硬着陆、任务失败等教学结果。
- 键盘：`Space` 播放/暂停，`←/→` 前后 5 秒，`R` 重播，`Home` 回到开始，`F` 自由轨道，`1–7` 镜头，`E` 拆解，`C` 剖面，`M` 声音，`Esc` 关闭浮层。
- 音效默认关闭，只有在用户点击“声音”后才会创建 Web Audio 上下文。程序生成的发动机、气流与再入声随飞行状态变化，关键事件有短音效；不会自动播放。
- 手机端重新排版：三维视窗 → 时间轴/控制 → 遥测；按钮最小高度 36px，镜头栏可横向滚动。
- 窗口缩放、WebGL 2 不可用提示、画质降级、暂停时释放动画开销、页面隐藏时暂停、资源释放。

## 5. 模拟模型、参数和局限

### 5.1 固定时间步之外：可重算的统一时钟

`src/simulation/FlightSimulator.js` 和 `StarshipSimulator.js` 不积累动画状态，也不使用 `setTimeout` 串起阶段。给定任意 `t`，`sample(t)` 会返回完整的一帧：

- 阶段 / 当前事件 / 下一事件；
- 一级与二级的世界坐标位置、高度、速度、垂直速度、燃料、发动机数量和节流；
- 姿态、栅格翼展开、着陆腿展开、再入热强度；
- 目标偏差和挑战结果。

因此暂停、倒放、拖动时间轴、倍速和重播都使用同一个时钟，不会发生动画错位。

### 5.2 视觉尺度

场景中飞行器本身按 **1 场景单位 = 1 米** 建模（Falcon 9 高约 68 单位，Starship 堆叠高约 125 单位）。为了同时看到发射台、数十公里的高度和着陆目标，世界坐标做了夸张压缩：

- Falcon 9：高度和航程乘以 `VIS_SCALE = 0.02`（1 单位 ≈ 50 m）；
- Starship：高度使用非线性映射 `35 × (alt/35)^0.32`，航程乘以 `0.004`。

这是**可视化压缩**，不是真实空间比例。速度、高度、燃料等仪表值使用原始米制参数，不从压缩后的屏幕坐标反推。

### 5.3 轨迹与速度

Falcon 9 的高度 / 下程使用分段关键帧，通过 **PCHIP 单调三次 Hermite 插值**在任意时间求值。速度由样条导数得到，因此位置、速度、方向连续；各次点火通过关键帧斜率与发动机状态体现。关键帧是可视化脚本坐标，不是实测弹道。

### 5.4 明确为估算的数值

以下值没有官方逐秒遥测，均为**简化模拟 / 估算**：

- 高度、下程、速度、垂直速度；
- 最大动压时刻；
- 一级/二级推进剂余量（按阶段线性估算）；
- 发动机节流曲线、点火台数切换；
- 栅格翼偏转、级间分离姿态、一级翻转角速度；
- 着陆腿展开时刻；
- 海上无人船与陆地着陆区的精确位置；
- 落点偏差、触地速度；
- 温度/热流、烟雾粒子、火焰形态；
- 所有镜头位置与镜头切换。

### 5.5 手动挑战模型

手动挑战是教学模型，不是 GNC（制导、导航与控制）仿真：

- 返航点火强度偏离 100% 会改变落点偏差；
- 着陆点火高度与横向偏移、再入迎角共同决定触地速度和偏离等级；
- 使用“开始点火高度 → 可用减速距离 → 触地速度”的简化公式，不重写轨迹关键帧；
- 输出成功 / 偏离 / 硬着陆 / 任务失败，并在任务总结中显示；
- 参数变化只影响结果评分与横向视觉偏移，不会变成真实的闭环制导。

### 5.6 Starship 模型

Super Heavy / Starship 是“Flight 13 时代构型”的**通用概念模型**：

- 33 台发动机的布局、栅格翼、热分离环、飞船襟翼和塔臂为教学建模；
- 热分离、返航、再入与塔臂捕获的逐秒时间均为概念演示；
- 塔臂捕获结果和飞船继续飞行不表示真实飞行测试结果；
- 不同 Starship 版本可能改变硬件细节。

### 5.7 HLS 月球架构

NASA 将 Starship HLS 定义为月球轨道与月面之间的载人着陆器。页面中的地球发射、轨道补给、地月转移、月球轨道会合、月面着陆和返回步骤均为**计划 / 概念演示**，不是已经完成的飞行。Artemis III 的具体时序、补给次数和硬件细节尚未最终确定。

### 5.8 Starbase 全设施探索器

- **公开资料支持的定性关系**：Super Heavy 是 Starship 系统的一级，设计为返回发射场并由发射塔捕获；Starbase 发射塔用于整合、测试与发射，两根机械臂可协助堆叠 Starship 并参与捕获返回助推器；Starship 是带襟翼与热防护系统的可重复使用上级。
- **比例估算**：发射塔高度、平台尺寸、机械臂长度、箭体直径/高度、发射台尺寸和储罐区位置均经过可视化调整，以方便同屏观察。场景单位为米级比例，但不是官方工程尺寸。
- **教学示意**：塔架内部提升机构与斜撑截面、机械臂铰点/传动/夹持面、发射台固定机构、导流结构、推进剂管路、箭体内部贮箱、环焊缝数量、发动机安装布局和全部接触点形状。
- **研究边界**：无法从公开资料确认的载荷路径、材料、阀门、液压、热环境、开口位置与真实运动顺序，均不以“官方”标签呈现。
- **两种姿态**是为了结构教学，而不是声称该状态在某个具体任务中按此方式发生；捕获姿态隐藏 Starship 是为了避免两级与塔臂接触关系互相遮挡。
- **X-Ray / 剖面**展示的是几何关系，不是真实内部剖切数据；内部贮箱只表示液氧/甲烷的相对位置，不能用于容量、质量或推进剂分配计算。

## 6. 性能与降级

- 画质档位：高 / 中 / 低，调整像素比、Bloom、阴影、粒子规模；
- 检测到移动设备或低核心数时默认使用“中”；
- 运行中若持续低帧率，自动再降一档并提示；
- WebGL 2 不可用时显示明确的说明页；
- 页面隐藏时暂停模拟；
- 模型、纹理、粒子、轨迹、环境与后期处理在场景切换/卸载时释放。
- 全设施探索器在打开时才创建独立 WebGLRenderer 与场景；关闭时暂停并释放，返回飞行演示后恢复原有播放状态。
- 探索器不运行飞行时钟；只进行姿态、拆解深度和镜头之间的短过渡，避免与飞行时间线混用。

## 8. 已知限制

- 轨迹和物理模型是为浏览器实时渲染而设计的教学近似，不用于任务规划、工程分析或真实飞行决策。
- 压缩后的空间尺度使高速飞行阶段的视觉速度与真实比例不同。
- 拆解视图是教学交互，不代表真实分离顺序。
- 火箭内部贮箱与管路为示意，不是工程图纸。
- 未展示整流罩抛离、载荷入轨、二级关机（SECO）或轨道插入等超出参考时间线的步骤。
- 声音为程序生成的电影化音效，不是 SpaceX 实录，也不模拟真实发动机声压级。
- 全设施探索器的几何是教学重建，不是可制造 CAD 模型；精确尺寸、质量、载荷、材料、阀门/液压路径和内部结构均未公开，也未在模型中工程化。
- 探索器的 121 个节点主要用于结构讲解，不等于真实 Starbase 的全部零件；塔架内部、储罐区、地面支持系统和连接点的数量、位置经过简化。
- 捕获姿态把 Super Heavy 简化地放到机械臂高度，以表达关系，不代表真实捕获轨迹、姿态或接触力学。
